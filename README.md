# 📊 Retail Sales Performance Dashboard | Power BI + SQL

## 🚀 Project Overview

This project demonstrates an end-to-end data analytics workflow, transforming raw retail data into actionable business insights using SQL and Power BI.

The goal is to analyze sales performance, customer behavior, and revenue trends to support data-driven decision-making.

---

## 🎯 Business Problem

Retail businesses often struggle to:

* Track revenue trends across time
* Understand customer purchasing behavior
* Identify patterns in order volume and value

This project solves these challenges by building an interactive dashboard for quick and effective analysis.

---

## 🔄 Data Workflow

1. **Data Extraction & Transformation (SQL)**

   * Cleaned and structured raw retail data
   * Performed joins across multiple tables
   * Applied aggregations for KPIs

2. **Data Visualization (Power BI)**

   * Built interactive dashboard
   * Created KPI cards and trend analysis visuals
   * Enabled filtering using slicers (Year, Month)

---

## 📌 Key Metrics (KPIs)

* 💰 Total Revenue
* 📦 Total Orders
* 👥 Total Customers
* 📊 Average Order Value

---

## 📈 Dashboard Features

* Monthly Revenue Trend Analysis
* Order vs Revenue Relationship (Scatter Plot)
* Customer Growth Visualization
* Interactive Slicers for dynamic filtering
* Clean and modern UI design
